PHASE 1 — SETUP (prerequisite for everything)
--------------------------------------------------------------

1.1  Disable visualization for batch runs
     In baseline_code/run_me.py, set: visualization = False
     This reduces runtime from ~1 min to ~2 sec per run.

1.2  Confirm conventional (gas) baseline works
     Set GSE_ELECTRIC = False and run once manually to verify
     the log output looks correct. You currently only have
     electric logs.

1.3  Fix simulation duration
     Many flights are "incomplete" in the current 4-hour runs.
     Check Plane_data.xlsx for the last scheduled flight and
     extend simulation_duration_hours until all flights can
     realistically complete. Document the chosen value.


PHASE 2 — BATCH RUNNER SCRIPT
--------------------------------------------------------------

2.1  Write batch_run.py
     The script should:
     - Loop over N_SEEDS random seeds (start with 30)
     - For each seed, run TWO simulations:
         * GSE_ELECTRIC = False (conventional)
         * GSE_ELECTRIC = True  (electric)
       using the SAME seed for both (paired design)
     - Parse the log file after each run and extract mean TAT
     - Save results to a CSV:
       columns: seed, tat_conventional, tat_electric

2.2  Write a log parser function
     The log format is consistent. The function should read
     a log file and return:
     - Mean TAT (the "Average X.X min" line)
     - Individual TAT per completed flight
     - Wait times (unload, load) per flight
     - Tasks completed per GSE
     - Battery consumed per GSE


PHASE 3 — NUMBER OF RUNS
--------------------------------------------------------------

3.1  Run 50 seeds for both scenarios (conventional + electric,
     equal fleet size n=5).

3.2  Plot CV convergence
     After each run, compute the cumulative coefficient of
     variation: cv = sigma / mu of the mean TAT across runs.
     Plot cv vs. number of runs for both scenarios.
     Stop collecting runs where cv flattens (typically ~30).
     Include this plot in the report as justification for
     the chosen number of runs.


PHASE 4 — PRIMARY HYPOTHESIS TEST (H0 vs. H1)
--------------------------------------------------------------

4.1  Compute paired differences
     d_i = TAT_electric(seed_i) - TAT_conventional(seed_i)
     for each run i.

4.2  Shapiro-Wilk normality test on the differences d_i
     from scipy.stats import shapiro
     stat, p = shapiro(differences)

     - If p > 0.05  -->  use paired t-test (step 4.3a)
     - If p <= 0.05 -->  use Wilcoxon signed-rank test (4.3b)

4.3a Paired t-test (if normal)
     from scipy.stats import ttest_rel
     stat, p = ttest_rel(tat_electric, tat_conventional)
     Significance level alpha = 0.05

4.3b Wilcoxon signed-rank test (if not normal)
     from scipy.stats import wilcoxon
     stat, p = wilcoxon(tat_electric, tat_conventional)
     Significance level alpha = 0.05

     Report: test statistic, p-value, and conclusion
     (reject / fail to reject H0).

4.4  Vargha-Delaney A-hat effect size
     A = count(electric_i > conventional_i) / N
     Interpretation:
       A = 0.50  -->  no effect
       A > 0.56  -->  small
       A > 0.64  -->  medium
       A > 0.71  -->  large

4.5  Box plot
     Side-by-side box plot: TAT conventional vs. TAT electric
     (equal fleet size). Include in Section 4.3 of the report.


PHASE 5 — SCALING EXPERIMENT (finding n*)
--------------------------------------------------------------

5.1  Run electric fleet for sizes neGSE in {5, 6, 7, 8}
     For each fleet size, run the same 30+ seeds.
     Collect mean TAT per run per fleet size.

5.2  Test equivalence against the conventional baseline
     NOTE: "Failing to reject H0" is NOT equivalence.
     Use a TOST (Two One-Sided Tests) equivalence test.

     Steps:
     a) Agree on an equivalence margin delta (e.g., +/- 5 min).
        This is the maximum TAT difference considered
        operationally acceptable. Justify this choice.
     b) For each fleet size, test:
          H_lower: mean(d) > -delta
          H_upper: mean(d) < +delta
        Both must pass at alpha = 0.05 to declare equivalence.

     n* = smallest fleet size where both tests pass.

5.3  Plot TAT vs. fleet size
     Mean TAT +/- 95% CI for each neGSE (electric), with the
     conventional baseline as a horizontal reference line.
     This is your main result figure.

--------------------------------------------------------------

6.1  Fleet size effect during peak hours  (sub-Q1)
     Using data from Phase 5:
     - Plot mean TAT and number of completed flights vs. neGSE
     - Identify at what fleet size TAT stops improving
     - Check if wait times cluster in time (peak hour effect)

6.2  Recharging impact on productive time  (sub-Q2)
     From the GSE utilization section of the logs:
     - tasks_completed per GSE (already in log)
     - battery_consumed per GSE (proxy for distance driven)
     Optional: add time-fraction logging (taxiing / working /
     charging) to run_me.py if exact fractions are needed.
     Compare these fractions between electric and conventional.

6.3  Bottlenecks  (sub-Q3)
     - Plot mean wait time before unloading and loading
       per scenario
     - Identify which flights consistently have the highest
       wait times — are they the same flights across seeds?
     - Optional: count deadlock activations (CBS stage 4) per
       run and check correlation with TAT
